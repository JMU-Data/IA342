### 8. Group status values

<figure class="lab-shot"><img width="784" height="456" src="../../assets/week-6/screenshots/house-exclude-nulls.png" alt="Null values selected with Exclude in the context menu" loading="lazy"></figure>

### 10. Calculate unit price

Create a calculated field named **unit price**, using:

```text
[price] / [area]
```

<figure class="lab-shot"><img width="677" height="379" src="../../assets/week-6/screenshots/house-unit-price.png" alt="The unit price calculated field uses price divided by area" loading="lazy"></figure>

### 11. Calculate lot size in square feet

Create a second calculated field named **lot size sq**, using:

```text
IF [lot_size] < 10 THEN [lot_size] * 43560
ELSE [lot_size]
END
```

For this exercise, the formula treats values below 10 as acres and the remaining values as square feet. This is a dataset-specific assumption, not a general way to identify units.

<figure class="lab-shot"><img width="473" height="205" src="../../assets/week-6/screenshots/house-lot-size.png" alt="The lot size sq formula multiplies values below 10 by 43560" loading="lazy"></figure>
