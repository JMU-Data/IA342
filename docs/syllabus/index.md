## Course Description

IA 342 focuses on Data Visualization, Business Intelligence, Visual Analytics, and Data Storytelling. While AI can analyze data for us, **humans still make decisions**; visualization supports human perception, judgment, communication, and accountability. Throughout this course, we will use industry-standard tools (ArcGIS, Tableau) to transform raw data into interactive dashboards and clear, evidence-based visual communications.

Regular attendance is critical, as a significant portion of the learning happens in class through hands-on practice, critique, and discussion. 

You may lose attendance credit for any of the following reasons:

## Tentative Course Roadmap

The course is organized into high-level modules rather than a rigid weekly schedule, allowing flexibility for deep dives into core tools:

1. **Module 1 — Course Introduction and Access Check**
   - Setting up accounts using your JMU institutional login and exploring the core question: *Why visualization?*
2. **ArcGIS / Spatial Visualization**
   - Map design and spatial intelligence.
3. **Tableau / Business Intelligence (BI)**
   - Connecting data, building primary charts, and exploratory data analysis.
4. **Mini Project / Checkpoint**
   - Synthesizing early spatial and BI skills.
5. **Visual Analytics and Dashboards**
   - Advanced calculations, interactivity, and dashboard design.
6. **Final Project**
   - End-to-end data storytelling and comprehensive visual analytics application.
