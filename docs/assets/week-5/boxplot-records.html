What does an average leave out?

Compare the median and middle half of each price distribution. Then show the individual records.

Box = Q1 to Q3. Line = median. Whiskers reach the most extreme observed values within 1.5 × IQR of the box. Values beyond those whiskers remain visible as points.

View the summaries and convention

Quartiles use linear interpolation at position (n−1)p, equivalent to a common type-7 quantile convention. Other software settings can produce slightly different quartiles. Horizontal jitter helps separate overlapping marks; it carries no data meaning.
