In the lab, adding IDNO as a dimension to Detail makes each mark represent one diamond record. A single overall mean does not show the distribution of individual diamonds. Filtering to IF changes which records are included; it does not demonstrate a causal effect of clarity on price.

This demo uses averages in its summarized modes. Tableau may start with SUM by default. Inspect the actual aggregation shown on each Tableau field pill.
