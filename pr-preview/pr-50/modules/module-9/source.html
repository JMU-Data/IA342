04 — Dimensions / Measures — Field Roles

Dimensions partition records into categories: CLARITY, RATER, or individual IDNO values.

Measures provide values to aggregate within those groups: AVG(PRICE), SUM(PRICE).

Data type describes the stored values: number, text, date, and so on.

RoleDisplay choice
DimensionDiscrete; numeric/date dimensions may also be continuous
MeasureContinuous or discrete

A numeric identifier is not an amount to sum. Blue/green is not the Dimension/Measure distinction.

05 — Aggregation and Level of Detail

Columns: **AVG(WEIGHT)**. Rows: **AVG(PRICE)**. 1. **No dimension:** one average pair. 2. **RATER / CLARITY on Detail:** one pair per category. 3. **IDNO on Detail:** one pair per record. Changing **AVG → SUM** changes the computation, not the grouping. At one row per ID, both return the same value. The HTML control **replaces** the Detail field. In Tableau, remove the old dimension before adding the next. Some record-level marks overlap.

09 — Drill Down — Date Hierarchies

**Drill down** adds a finer level of detail. **Drill up** regroups it at a higher level. `Year → Quarter → Month → Day` Use **+** and **−** to move between the available levels. In this example, all 24 monthly rows stay included. A year total splits into quarters, then months; the total stays unchanged. For discrete dates, **+** adds the next level while keeping its parent. Drilling down is different from filtering to one year.

Tableau Help

10 — Date Grouping — MONTH vs YEAR + MONTH

MONTH(Order Date) alone groups all January records together, irrespective of year.

YEAR(Order Date) + MONTH(Order Date) creates two levels of discrete headers: Year, then Month.

Read the Columns shelf and the header structure together. January under 2024 is a different group from January under 2025.

Both examples are discrete. The added Year grouping—not a color change—separates the years.

A month-level date value can also retain the year in one field. Blue/green alone does not determine which date components are retained.

Tableau Help

11 — Drill Down — A Custom Hierarchy

A hierarchy organizes dimensions into an ordered path from summary to detail.

CLARITY → IDNO

At CLARITY level, one bar summarizes a category. Expanding adds a bar for each ID within that category.

Collapsing recomputes the average from those records. It does not sum the child prices or remove them.

Drill down changes the grouping level.
A filter changes the included subset.

Diamonds has no date field. The same hierarchical idea applies to categorical dimensions.

13 — Sort — Field and Nested Sorts

Sort changes member order while leaving their aggregate values unchanged.

Here the outer dimension is COLOR; the inner dimension is CLARITY. The measure is AVG(PRICE).

Field sort: one CLARITY ordering computed over the retained records, repeated in each COLOR pane.

Nested sort: a separate ranking of CLARITY inside each COLOR pane.

The same label can have a different position in each pane under a nested sort.

15 — Group — Combine Category Members

A Group creates a new categorical dimension by assigning several existing members to one label.

VS1 + VS2 → VS

The grouped chart combines the underlying records and recomputes the measure.

It does not delete rows or turn distinct diamonds into duplicate records.

Group result: a category label.
Set result: IN / OUT membership.

The merged average weights every source row equally. Bins and rule-based calculated categories are other grouping techniques—not the Group command itself.

18 — Set — Top 5 by Price

20 — Filters — Levels and Execution Order

A filter limits the data or results used in an analysis. Its level determines when the restriction is applied.

Execution order ↓What this level doesExample
1Extract filterLimits the rows copied into an extract when it is built.Keep only a selected date range in the extract.
2Data source filterRestricts rows available to worksheets using that source.COVID source: counts ≥ 0.
3Context filterDefines a worksheet subset before dependent filters.GIA first, then Top 5 within GIA.
4Dimension filterSelects dimension members before the view's aggregation.Keep CLARITY = VS1.
5Measure filterTests aggregated measures at the view's level of detail.Keep AVG(PRICE) > 2,500.
6Table calculation filterHides marks after table calculations; their input data stay included.Hide a calculated result without recomputing the others.

The level—not the order in which you add filters—determines execution.

21 — Filters — Same Threshold, Different Results

Both views apply an AVG(PRICE) > 2,500 condition. Why do they display different rows?

Aggregation chooses what to test (e.g., All Values vs Average); comparison chooses the rule (Range / At Least / At Most). The filter level of detail determines which rows remain. Click either screenshot to enlarge.

22 — Trend Lines — Fit the Displayed Data

A linear trend line fits: `fitted PRICE = intercept + slope × WEIGHT` **Slope** summarizes the direction and rate of change. **R²** summarizes fit to these plotted values; it is not proof of causation. ### In Tableau Keep **IDNO on Detail**. Remove categorical Color for one overall fit, then use **Analytics → Trend Line → Linear**. Filter by RATER to recompute the fit. In Tableau, use **one fit without color factors**, allow a free intercept, and turn off confidence bands to match this example.

24 — Reference Lines — Value and Scope

A reference line locates a benchmark on a continuous axis. Unlike a trend line, it does not fit the relationship between two measures.

### Choose the reference value - **Constant:** a specified value, such as WEIGHT = 1.0. - **Statistic:** a mean or median of the relevant plotted values. - **Parameter:** a value the viewer controls. A **reference band** covers an interval; a **distribution band** uses statistical ranges.
### Choose its scope | Scope | How many references? | |---|---| | Entire Table | One for the view | | Per Pane | One for each pane | | Per Cell | One for each cell | In **Price vs Weight**, add a horizontal mean-PRICE line. Then add RATER to Columns and compare Entire Table with Per Pane.

An average of displayed group marks may differ from the overall row-level mean when group sizes differ. At the IDNO level here, each mark corresponds to one record.

Tableau Help

25 — Parameters — One Adjustable Value

A parameter stores one current number, text value, or date.

It affects a view only through an object that uses it.

Here price level controls a reference line and this category:

IF [PRICE] > [price level] THEN
  'Above threshold'
ELSE
  'At or below threshold'
END

One number → two effects.
The record values stay unchanged.

29 — Actions — Connect Interaction to Results

An action connects a user's interaction in a source view to a defined response in a target.

USER INTERACTIONSelect · Hover · Menu
→
ACTION RULEWhat should change?
→
TARGETA view, a set, or a parameter
Action typeTargetExample result
FilterAnother worksheetSelect a state → show only that state's counties.
Change Set ValuesAn existing setSelect counties → update membership; a calculation or Color uses the set.

32 — Data Guide and Explain Data

Data Guide provides view context: filters, fields, summaries, and detected outliers.

Explain Data evaluates statistical explanations for a selected mark. It does not establish the cause of the observed result.

Use Data Guide where enabled; explanations vary with the view and selection.
